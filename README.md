# E-Commerce Sales Performance Dashboard | Excel

## 📊 Project Overview
Excel dashboard analyzing 50K+ e-commerce transactions to track revenue, profit, and expenses by product line, region, and payment method. Built using Power Query and PivotTables for automated reporting.

## 🛠️ Tools Used
`Advanced Excel` `Power Query` `PivotTables` `PivotCharts` `Data Cleaning`

## 📈 Key Insights
- **Cash** was most profitable payment method with 25.6M profit
- **Healthcare** product line generated highest revenue at 21.3M
- **Africa** led transaction volume with 839 orders
- **R&D** had highest revenue but also highest average expenses at 17%

## 🔍 Features
- **Area Chart**: Number of transactions by Region
- **Bar Chart**: Total profit by Payment Method  
- **Line Chart**: Total expense comparison by Category
- **Pie Chart**: Revenue vs Average Expense by Department
- **Power Query**: Automated data cleaning and transformation
- **PivotTables**: Dynamic summarization of 50K+ rows
